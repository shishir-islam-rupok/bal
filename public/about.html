ABOUT FILE SHIFT

Useful tools without the noise.

File Shift is a small toolbox for everyday file work. It helps people convert common images and media without creating an account or sending files to a conversion service.

What we provide

The image converter supports common JPG, PNG, WEBP, GIF, BMP, and AVIF inputs with JPG, PNG, WEBP, and AVIF output where the browser supports encoding. The media tool supports common audio and video formats, local previews, batch conversion, and timeline-based trimming.

Privacy as a product choice

Image conversion uses browser APIs. Audio and video conversion uses FFmpeg WebAssembly in the browser. This design keeps the main file workflow local and makes the privacy promise understandable.

Clear limitations

Browser processing depends on the user's device and browser support. Very large media files can take time or fail on low-memory devices. We explain these limits instead of presenting an unreliable result as guaranteed.

Contact

Questions, accessibility issues, or conversion bugs can be reported through the Contact page.
